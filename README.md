# Brew-master 🍺

**«Пивная Империя» (Beer Empire / Brew-master)** — это экономический симулятор пивоварни (Brewery Tycoon) с элементами текстовой настольной RPG и асинхронным PvP в формате Telegram-бота для личных и групповых чатов.

### Суть игры
Игроки примеряют на себя роль владельцев фэнтези-пивоварен в мире алхимиков, гоблинов и эльфов:
* **Варите пиво**: Используйте уникальные пропорции ингредиентов и нелинейную математику. Каждая варка — это бросок кубиков против сложности рецепта, где можно рискнуть всем в механике «Терпения пивовара» (*Push Your Luck*).
* **Управляйте бизнесом**: Нанимайте алхимиков, караванщиков и торговцев, следите за их усталостью и лояльностью, стройте фермы и продавайте пиво фракциям с учетом динамического спроса.
* **Исследуйте мир**: Отправляйте агентов в опасные текстовые рогалик-экспедиции за редкими ингредиентами и лором.
* **Взаимодействуйте с сообществом**: Объединяйтесь в гильдии прямо в групповых чатах Telegram, участвуйте в слепых аукционах, устраивайте совместные рейды на боссов и совершайте экономические диверсии против конкурентов (подкуп инспектора, чёрный пиар).
* **Гейм-мастер на базе ИИ**: Игровой мир и его события динамически генерируются и адаптируются невидимым LLM-слоем (Gemini).

## 🛠️ Стек технологий

- **Язык**: Python 3.13+
- **Пакетный менеджер**: [uv](https://github.com/astral-sh/uv) (быстрая и современная альтернатива pip/poetry)
- **Telegram Bot API**: [aiogram 3.x](https://github.com/aiogram/aiogram) (асинхронный фреймворк)
- **База данных**: [PostgreSQL](https://www.postgresql.org/)
- **ORM / БД Драйвер**: [SQLAlchemy 2.x](https://www.sqlalchemy.org/) + [asyncpg](https://github.com/MagicStack/asyncpg) (полностью асинхронная работа)
- **Миграции**: [Alembic](https://alembic.sqlalchemy.org/)
- **Валидация данных**: [Pydantic v2](https://docs.pydantic.dev/) & `pydantic-settings`
- **ИИ-слой (Game Master)**: [google-genai](https://github.com/googleapis/google-genai) (Gemini SDK)
- **Линтер и форматирование**: [Ruff](https://github.com/astral-sh/ruff)

## 🚀 Быстрый старт

### 1. Подготовка окружения и установка зависимостей

Убедитесь, что у вас установлен [uv](https://github.com/astral-sh/uv).

Выполните команду для автоматического создания виртуального окружения и установки всех зависимостей (включая инструменты разработки):

```bash
uv sync
```

### 2. Настройка конфигурации

Создайте файл `.env` на основе шаблона `.env.template`:

```bash
cp .env.template .env
```

Заполните переменные в `.env` (токен Telegram-бота, реквизиты PostgreSQL и ключ Gemini API).

### 3. Применение миграций базы данных

Для применения миграций и создания таблиц в базе данных выполните команду:

```bash
uv run alembic upgrade head
```

При добавлении новых SQLAlchemy моделей в `src/database/models/` создайте автомиграцию:

```bash
uv run alembic revision --autogenerate -m "description"
```

### 4. Линтинг и форматирование кода

Для проверки кода на соответствие стандартам:

```bash
uv run ruff check .
```

Для автоматического исправления ошибок форматирования и сортировки импортов:

```bash
uv run ruff format .
```
