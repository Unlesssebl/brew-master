# Внедрение атмосферного Location-Based UX и скрытых механик (v2)

## Описание цели

Переупаковать интерфейс бота в концепцию **«Карты Города»** с 7 локациями, каждая из которых отвечает строго за свой круг механик. Тон — иронический фэнтези. Web Apps не используются.

## Замечания по UX (устранённые)

- **Лаборатория → Варочный Зал**: «Лаборатория» ассоциируется с наукой, не с пивоварением. «Варочный Зал» — атмосферно и точно описывает место, где стоят котлы.
- **Погреб — только просмотр**: Покупка сырья перенесена на Торговую площадь. Погреб — склад, а не магазин.
- **Торговая площадь разделена на 2 действия**: `📦 Закупить сырьё` и `💰 Сбыть партию` — разные по смыслу и финансовому потоку действия, не смешиваются.
- **Тёмный переулок — два подменю**: `🗡️ Нанять шпиона / Устроить диверсию` и `🍶 Гоблинский базар (Чёрный рынок)` — тематически близки (оба нелегальны), но функционально разделены.
- **Профиль — фэнтезийная «Летопись Мастера»**: Золото, репутация и влияние были скрыты в тексте главного меню. Теперь — отдельный экран с атмосферным оформлением.

### 3. Локация: ⚖️ Торговая площадь

#### [NEW] [market.py](file:///f:/Work/Projects/brew-master/src/bot/handlers/market.py)
**Блок «Закупить сырьё» (плавающие цены):**
- Отображение текущих цен на 4 ингредиента с трендом (↑↓).
- Покупка отдельных ингредиентов (не пакетом).
- Цены обновляются фоновой задачей (см. ниже).

**Блок «Сбыть партию»:**
- Список готовых бочек игрока (`Batch.is_completed == True`).
- Выбор фракции: Гномы (x2, макс. 50 бочек), Эльфы (x0.8, макс. 500), Гоблины (только брак x0.2).
- Расчёт цены: `calculate_final_barrel_price(base, k_market, k_quality, d_penalty)`.
- Запись в `TransactionLog` для последующего расчёта роялти.

#### [MODIFY] [economy_dal.py](file:///f:/Work/Projects/brew-master/src/database/dal/economy_dal.py)
- `sell_batch(session, batch_id, fraction, market_type)` — списание бочек, зачисление золота, запись в `TransactionLog`.
- `get_ingredient_prices(session)` — текущие цены сырья из новой таблицы `economy.ingredient_prices`.
- `buy_ingredient(session, player_id, resource_type, amount)` — покупка конкретного ингредиента по актуальной цене.

#### [NEW] Модель: `IngredientPrice` в [economy_models.py](file:///f:/Work/Projects/brew-master/src/database/models/economy_models.py)
```python
# Хранит текущую рыночную цену для каждого ингредиента
class IngredientPrice(Base):
    ingredient: str     # malt | water | hops | yeast
    price: Decimal      # текущая цена за единицу
    trend: int          # +1 / -1 / 0 (для стрелки на экране)
    last_updated: datetime
```

**Алгоритм плавающих цен (балансный):**
```
base_costs = {malt: 1.0, water: 0.1, hops: 2.0, yeast: 1.5}
Каждые 4 часа фоновый воркер:
  1. Берёт объём покупок каждого ингредиента за последние 4ч (из лога).
  2. new_price = base_cost * (1 + 0.1 * (purchases / 100))
  3. Clamp: base_cost * 0.5 ≤ new_price ≤ base_cost * 3.0
  4. Плавно: new_price = old_price * 0.7 + new_price * 0.3  (EMA-сглаживание)
```
> Цена не может упасть ниже 50% и вырасти выше 300% от базы — защита от экстремумов.

## Verification Plan

### Цикл продажи
Сварить партию → Тёмный Погреб (убедиться, что нет кнопки «Купить») → Торговая площадь → Сбыть партию Гномам → проверить зачисление золота и запись в `TransactionLog`.

### Цикл плавающих цен
Сделать несколько покупок одного ингредиента → дождаться тика воркера → убедиться, что цена выросла, но не превысила 300% от базы.

### Цикл патента
Сварить серийно (Strength ≥ 8, Aroma ≥ 7) → войти в Варочный Зал → Патентное бюро → запатентовать → проверить статус и ежедневный налог.

### Цикл PvP
Тёмный переулок → Сеть осведомителей → выбрать цель → Подкуп инспектора → проверить расчёт шанса, списание золота и влияния, появление дебаффа у цели.

### Профиль
Убедиться, что «Летопись» отображает актуальные данные из БД и верно считает статистику.
